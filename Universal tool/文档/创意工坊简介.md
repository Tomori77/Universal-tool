## 模组简介

Universal Tool 是一个围绕“万能”主题设计的综合性模组。从一台全新的核心工作台出发，逐步解锁便携设备、加工机器与自动化生产设施，减少来回奔波和重复操作，并提供便捷的技能训练与属性成长途径。

核心循环：制造万能工作台 → 建立万能精华生产线 → 扩展自动化设备，最终实现资源循环生产、解放双手。

- **便携工具**：便携工作台（内置 5 种台面）、便携出货箱、伐木/挖矿/掘地三合一的镐尖斧。
- **成长装置**：技能训练器（提升已有技能）、增幅器（临时增益、可破上限）、属性灌注器（永久提升属性）。
- **加工与能源**：凝华器、万能分解机、复制器、精华电池、万能修复器（一键鉴定与去诅咒）。
- **自动化**：自动凝华器、自动复制器、自动生成器、矿物生成机、自动熔炉、自动农业机、流体提取器、物品收集器。
- **物流**：输入/输出终端，同频道隔空传输，支持顺序/轮询模式与类别筛选。
- **游戏内设置**：倍率、上限、消耗等均可在 Mod Options 中调整。

GitHub（源码与 Mod 制作教程）：https://github.com/Tomori77/Universal-tool

## 更新公告

### 2026-08-16 · 自动化时代
新增万能生成器、自动凝华器、输入/输出终端、物品收集器、万能肥料；万能护身符重做为“催化剂 + 精华免死复活”。

### 2026-08-18 · 自动化增强
新增自动生成器、自动复制器；优化输入器的轮询跨小时记录与分配逻辑。

### 2026-08-20 · 物流与回收调整
输入器/输出器更名为输入终端/输出终端，新增传输速率（10/50/100/200/500/1000 或整格），独立保存；自动化设备需同时相邻输入器和输出器才工作，条件不足不消耗材料；万能分解机产出调整（技能书 100 / 普通装备 10 / 稀有 50 / 高级 100 / 垃圾 1）；物品收集器改为自带 6×6 空间；万能肥料配方改为 肥料×2 + 万能精华×10。移除便携魔法炮、同伴训练终端。

### 2026-08-21
新增流体提取器（靠近水源提取工业用水）、自动农业机（自动播种浇水，需工业用水）；优化部分贴图。

> 完整版本变化见 GitHub 的 [`更新公告.md`](https://github.com/Tomori77/Universal-tool/blob/main/Universal%20tool/文档/更新公告.md)。
