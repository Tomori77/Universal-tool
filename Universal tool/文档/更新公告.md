## 2026-08-29 · 自动设备运行机制与万能肥料修复

### 修复

- 万能肥料改为将作物推进至实际可收获的阶段，避免部分作物被推进到枯萎阶段而无法收获。

### 调整

- 自动凝华器、自动复制机和自动熔炉开机后每小时消耗万能催化剂×1；无论本轮是否成功运行配方，都会消耗该催化剂。
- 自动凝华器的三条结晶产出配方保持不变：魔力结晶×1、太阳结晶×1、大地结晶×1分别产出对应数量的万能精华。
- 自动凝华器耗电调整为 `20`，并且必须连接输入器和输出器。
- 自动复制机的结晶和金属锭配方调整为投入 `5` 个、产出 `10` 个，并按输入器格子顺序处理，不按固定配方优先级处理。
- 自动复制机耗电调整为 `20`，每 `10` 分钟执行一次。
- 自动生成器取消内部存储，直接通过输入器和输出器运行配方，并持续占用 `1000` 电力；配方调整为万能催化剂×5 → 万能催化剂×10、肥料×5 → 万能肥料×30。
- 自动熔炉改为每 `10` 分钟运行一次，每次最多处理 `10` 个可熔炼物品，允许按输入器顺序混合处理不同物品；每个物品仍使用原版熔炉配方。
- 自动熔炉改用机器本体中的万能催化剂作为开机消耗材料，耗电调整为 `20`。
- 所有上述自动设备不会因材料不足、配方无法运行或电力不足自动关闭，只能由玩家手动关闭。
- 输入终端新增 `1` 个/次、`2` 个/次、`5` 个/次三档传输速率。

### 验证状态

- 代码、数据表、本地化和 Release 编译已通过；以上功能仍需游戏内测试。

## 2026-08-22 · 自动加工设备与农业机制更新

### 新增

- 新增 **UT_矿物生成机**，在机器本体保存原版矿石模板。
- 新增 **UT_自动熔炉**，使用机器本体中的万能精华作为燃料。
- 两台机器均在自动工厂制造，耗电均为 `100`。
- 新增矿物生成机和自动熔炉的 `32×32` 透明 PNG 贴图。

### 功能

- 矿物生成机仅支持原版矿石；目标矿石放入机器本体后不会被消耗。
- 矿物生成机从相邻输入器消耗万能精华，每次消耗 `100` 个并生成目标矿石 `1` 个，产物必须进入相邻输出器。
- 自动熔炉从相邻输入器取得矿物，使用原版熔炉配方，每次处理 `1` 个物品并将产物送入相邻输出器。
- 自动熔炉每次处理消耗 `1` 个机器本体中的万能精华，燃料消耗与原版熔炉每次处理的基础燃料消耗一致。
- 两台机器均按每 `10` 分钟执行一次计算，每小时最多执行 `6` 次；离线补算按每小时 `6` 次处理。
- 自动农业机播种改为：从范围内找到第一个可种植地块后，按当前横向方向播种一行，每 `10` 分钟执行一次。
- 自动农业机浇水改为：范围内有种子地块且尚未浇水时进行浇水，每 `10` 分钟执行一次，每块消耗 `1` 个工业用水。
- 独立建立自动设备统一时间调度器，实时模式每 `10` 分钟触发一次，离线模式每小时补算 `6` 次。
- 自动凝华器、自动复制机、自动生成器、物品收集器、输入终端、流体抽取器、自动农业机、矿物生成机和自动熔炉统一接入该调度器。
- 自动复制机、自动生成器、流体抽取器和自动农业机移除原有独立的每小时执行入口，改由统一调度器调用单次 Tick，避免重复执行。

### 验证状态

- 数据表、三语言本地化文件和 Release 编译已检查通过。
- 两张新贴图已完成去白底、裁剪、去除水印区域并输出为透明 PNG。
- 矿物生成机的原版矿石识别、材质复制、输入输出流程仍需游戏内验证。
- 自动熔炉的原版配方匹配、万能精华消耗、输入输出流程仍需游戏内验证。
- 自动农业机的横向播种、范围浇水和每 10 分钟执行流程仍需游戏内验证。
- 全部自动设备统一调度后的实时执行、离线补算和设备产能仍需游戏内验证。

## 2026-08-20 · 自动农业与物流调整


### 新增

- 新增 **UT_自动农业机**。
- 自动农业机拥有 6×6 储物空间，可设置种植范围。
- 自动工厂新增自动农业机制造配方。

### 功能

- 自动农业机按时间处理种子并尝试种植符合条件的农田。
- 有工业用水时，机器会尝试为新种植地块浇水。
- 输入终端新增传输速率设置：10、50、100、200、500、1000 个或整个物品堆。
- 传输速率按输入终端分别保存，旧配置默认使用整个物品堆。

### 调整

- 自动凝华器、自动复制机和自动生成器需要同时具备输入器和输出器才会工作。
- 输出器已满或供料条件不满足时，不消耗本轮材料和催化剂。
- 自动生成器新增肥料生成配方。
- 物品收集器使用自身 6×6 容器保存收集到的物品，装满后停止收集。
- 万能肥料配方调整为肥料×2 + 万能精华×10。
- 万能分解机的技能书和装备回收产出调整。

### 移除

- 移除 UT_便携魔法炮。
- 移除 UT_同伴训练终端。

### 验证状态

- 数据表和项目编译已检查。
- 万能肥料的实际施肥流程、自动农业流程和部分自动化行为仍需游戏内验证。

## 2026-08-16 · 自动化时代

### 新增

- UT_万能生成器：生成水、万能肥料和万能催化剂。
- UT_万能催化剂：自动设备的运行材料。
- UT_自动凝华器：自动加工结晶并产出万能精华。
- UT_自动复制机：自动复制指定资源。
- UT_自动生成器：自动生成催化剂或肥料。
- UT_输入器 / UT_输出器：自动设备的供料与收货容器。
- UT_物品收集器：定时收集范围内的地面物品。
- UT_流体抽取器：尝试从水方格生产工业用水。
- UT_自动农业机：尝试自动播种并浇水。
- UT_输入终端 / UT_输出终端：使用频道配对进行物品传输。

### 调整

- 自动工厂的制造入口调整为万能工作台。
- 万能护身符改为容器式背包道具，使用催化剂和万能精华触发免死效果。
- 复制器支持输入数量进行批量复制。
- 设置菜单增加自动化设备相关选项。
- 输入终端支持顺序和轮询模式。
- 输出终端支持类别筛选。

### 已知问题

以下功能当时尚未完成游戏内验证：

- 万能肥料的作物放置流程；
- 自动农业机的完整播种与浇水流程；
- 流体抽取器的水方格检测；
- 自动设备的离家补算；
- 护身符的死亡拦截；
- 频道终端的持久化和筛选行为。
