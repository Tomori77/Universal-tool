# Elin Mod 制作文档入口

## 权威来源

| 需求 | 文档 |
|---|---|
| 制作流程、目录、发布标准 | `Mod制作规范.md` |
| 已验证 API、机制与坑点 | `反编译速查.md` |
| 工具、路径、命令与依赖 | `工具与依赖.md` |
| 入门与专题教程 | `AI-Mod制作教程\` |
| 辅助工具 | `tools\` |
| 本地资料与离线副本 | `docs\` |

## 推荐阅读顺序

1. 先读本页，判断 Mod 类型。
2. 读 `AI-Mod制作教程\00_总览与快速上手.md`。
3. 开发前创建 `<Mod名>设计规范.md`，遵循 `Mod制作规范.md`。
4. 做物品、工作台或配方：读 `AI-Mod制作教程\01_物品与配方.md`。
5. 做特殊行为或 Harmony：读 `AI-Mod制作教程\02_Trait与游戏机制.md`，再查 `反编译速查.md`。
6. 做设置菜单：读 `AI-Mod制作教程\03_配置UI_ModOptions.md`。
7. 编译、反编译、贴图和排错：读 `AI-Mod制作教程\04_工具链与工作流.md` 与 `工具与依赖.md`。

## 按目标查找

- 新物品 / 工作台：`01_物品与配方.md`
- 混合机配方：`01_物品与配方.md`，再查 `反编译速查.md`
- 自定义 Trait：`02_Trait与游戏机制.md`
- 周期设备、容器、工具、发电：`02_Trait与游戏机制.md`
- Harmony 补丁：`02_Trait与游戏机制.md`、`反编译速查.md`
- Mod Options：`03_配置UI_ModOptions.md`
- 构建、打包、日志：`04_工具链与工作流.md`、`工具与依赖.md`

## 信息归位原则

- 流程规则只以 `Mod制作规范.md` 为准。
- API 和反编译结论只以 `反编译速查.md` 为准。
- 工具和路径只以 `工具与依赖.md` 为准。
- 教程负责解释、示例和导航，不重复维护全部底层资料。
- `docs\` 为本地资料目录，不随仓库上传，包含官方文档副本、反编译源码、参考模组、发布包与图片工作区；本项目额外验证的结论记录在速查文档中。
