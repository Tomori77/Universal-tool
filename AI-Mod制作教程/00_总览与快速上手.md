# 00 · 总览与快速上手

> 本教程帮助你选择 Mod 类型并跑通最小闭环。流程查根目录 `Mod制作规范.md`，API 查 `反编译速查.md`，工具查 `工具与依赖.md`。
> 当前基线：Elin EA 0.23.x、BepInEx 6.0.0-pre.1。

## 阅读顺序

1. 本页：环境、类型、目录和验证链。
2. `01_物品与配方.md`：物品、工作台、混合机和本地化。
3. `02_Trait与游戏机制.md`：特殊行为、设备和 Harmony。
4. `03_配置UI_ModOptions.md`：游戏内设置菜单。
5. `04_工具链与工作流.md`：反编译、构建、贴图和排错。

## Mod 类型

| 类型 | 内容 | DLL |
|---|---|---|
| 数据表 | 物品、配方、技能等 | 通常不需要 |
| 插件 | 代码改变玩法 | 需要 |
| 混合 | 数据表 + 自定义 Trait | 需要 |
| 纯资源 | 贴图、音效、立绘 | 不需要 |
| 语言包 | 文本替换 | 不需要 |
| 设置菜单 | Mod Options 页面 | 可选 |

只使用游戏内置 Trait 的数据表 Mod 可以不带 DLL；使用自定义 Trait 必须带入口 DLL 并注册程序集。

## 标准目录

```text
<Mod名>\
├── <Mod名>.csproj   # 有 DLL 时
├── Script\          # 源码，仅开发目录
├── LangMod\         # xlsx 与本地化
├── Texture\         # 物品贴图
├── package.xml
└── 设计文档\
```

发布包放在 `docs\待转移\<Mod名>\`，只包含 DLL（如有）、`package.xml` 和按需资源；不要包含源码、工程、obj、refs、pdb。用户负责复制到游戏 `Package\`。

## 最小闭环

纯数据 Mod 的最小步骤：

1. 创建 `LangMod\EN\`。
2. 用 `xlsxwriter` 生成 `Thing` sheet，三行头后写一个物品行。
3. 给可制作物品填写 `factory`、`components` 和 `recipeKey`。
4. 按需添加 `LangMod\CN\SourceLocalization.json` 与 `Texture\<id>.png`。
5. 写 `package.xml`，整理发布包。
6. 按验证链检查。

需要特殊行为时，再添加 `net472` 工程、插件入口、自定义 Trait 和 Harmony；具体写法见 02。

## 三文档工作流

每个 Mod 开发前创建：

- `<Mod名>设计规范.md`：需求、决策、实现步骤和验证方式。
- `<Mod名>物品清单.md`：面向玩家的物品说明。
- 反编译结论更新到根目录 `反编译速查.md`。

## 完成标准

1. 编译无错误（有 DLL 时）。
2. `BepInEx\LogOutput.log` 有插件加载记录，不能是 `0 plugins to load`。
3. `Player.log` 有源表导入记录 `#mod-content added`。
4. 游戏内物品可制造、放置或使用，贴图和 Trait 正常。
5. 配方重建无 `Failed to create recipe`。
6. 设置页面和 cfg 文件正常（如有）。
