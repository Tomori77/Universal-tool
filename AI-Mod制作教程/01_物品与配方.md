# 01 · 物品与配方

> 本页负责 Thing、Recipe、本地化和贴图。项目流程查 `Mod制作规范.md`，API 机制查 `反编译速查.md`。

## 1. xlsx 通用规则

- 文件放在 `LangMod\<语言>\`，不要放 `Data` 子目录。
- 文件名任意；sheet 名使用游戏源表名，如 `Thing`、`Recipe`、`Element`。
- 前三行固定为：字段名、类型、默认值；第 4 行起为数据。
- id 为空会终止导入，数据行中间不能有空行。
- 生成必须使用 `xlsxwriter`；`openpyxl` 只用于读回校验或读取官方表。

## 2. Thing 表

Thing 表用于物品本体和工作台配方。常用字段如下：

| 字段 | 作用 | 示例 |
|---|---|---|
| `id` | 唯一 id | `my_item` |
| `name` | 英文名称 | `My Item` |
| `category` | 分类，影响堆叠和装备判定 | `processor`、`tool`、`fertilizer` |
| `_tileType` | 占格类型 | `Obj` 可跨过，`ObjBig` 阻挡 |
| `_idRenderData` | 渲染数据 | `@obj` |
| `size` | 格子尺寸 | `1,1` |
| `recipeKey` | 配方解锁 | `*` 初始习得 |
| `factory` | 制作台 id | `workbench` |
| `components` | 材料，格式为 id/数量 | `branch/1,log/10` |
| `defMat` | 默认材质 | `oak` |
| `value`、`LV`、`quality`、`HP`、`weight` | 基础数值 | 按需求填写 |
| `electricity` | 发电或耗电 | 正数发电、负数耗电 |
| `trait` | Trait 值 | `Workbench` 或自定义值 |
| `elements` | 元素字段 | 采集工具不要依赖此列注入元素 |
| `offense` | 攻击力数组 | 空或至少两个值 |
| `detail` | 英文描述 | 文本 |

完整 51 列顺序应以项目现有生成脚本和官方 `thing.md` 为准，不要凭记忆重排字段。

### 关键坑点

- `offense` 必须为空或长度至少为 2；长度 1 可能导致配方渲染越界。
- 默认值行不要把 `factory` 设为 `workbench`，否则空字段可能产生意外配方。
- xlsx 中写空字符串可能回退默认值；要覆盖默认值时使用不存在的 id（如 `none`）。
- `defMat` 使用 `oak`，不要使用无效的 `wood`。
- 工具通常使用非 melee 分类并让 `offense` 留空。
- Thing 表写入已有官方 id 会整行替换，可能破坏原物品；给已有物品加配方请使用运行时补丁。

## 3. 工作台配方

普通工作台不使用 Recipe 表。新建物品行时填写：

- `factory`：工作台物品 id，例如 `workbench`。
- `components`：材料列表，例如 `branch/1,log/10`。
- `recipeKey`：`*` 表示初始习得。

给现有工作台加配方，只需新建物品行并把 `factory` 指向该工作台。工作台自身也可以由另一个工作台制造。

## 4. Recipe 表

Recipe 表用于混合机、提炼机等 `TraitCrafter` 设备，不用于普通工作台。

| 字段 | 作用 |
|---|---|
| `id` | 配方唯一整数 id，避开官方区间 |
| `factory` | 匹配设备的 `TraitCrafter.IdSource` |
| `type` | `Resource`/`FixedResource` 等产物类型 |
| `thing` | 产物 id |
| `num` | 产出数量 |
| `sp`、`time` | 消耗和耗时，均为 int |
| `ing1`、`ing2`、`ing3` | 材料纯 id，不带数量 |
| `tag` | 显示条件，通常必须包含 `known` |

`Grind` 通常不生成普通产物；需要产物时使用 `Resource` 或 `FixedResource`。材料列写 `branch`，不要写 `branch/1`，否则可能查表失败。

## 5. 本地化

路径：`LangMod\<语言>\SourceLocalization.json`。常用键：

```json
{
  "SourceThing.my_item.name": "我的物品",
  "SourceThing.my_item.detail": "这是描述。"
}
```

物品字段使用 `SourceThing.<id>.<字段>`，技能和元素使用 `SourceElement.<id>.<字段>`。常用语言代码为 `EN`、`CN`、`ZHTW`、`JP`。

## 6. 贴图

- 路径：`Texture\<物品id>.png`。
- 规格：32×32、透明背景、俯视视角、主体占满。
- 文件名必须与物品 id 一致；通常无需写替换代码。
- 封面为包根的 `preview.jpg`，处理命令查 `04_工具链与工作流.md`。

## 7. 验证

1. 用 openpyxl 读回检查三行头、列数、数据行和字符串。
2. 打包后检查 `Player.log` 是否出现 `#mod-content added 'Thing/<id>'`。
3. 游戏内确认配方可见、物品可制造/放置、贴图和 Trait 正常。
4. 混合机配方确认没有 `Failed to create recipe`。
